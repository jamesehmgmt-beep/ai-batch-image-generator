<objective>
Create the recovery manager system for detecting and recovering orphaned jobs.

Purpose: Jobs can get stuck in 'processing' state if the process crashes, network fails, or kie.ai doesn't respond. This manager detects jobs stuck for too long (15 minutes) and resets them to 'pending' so they can be retried.

Output: Database query utilities and a recovery manager that can be started to run periodic checks.
</objective>

   - Create Supabase client
   - Calculate threshold timestamp: `new Date(Date.now() - timeoutMinutes * 60 * 1000)`
   - Query generations table:
     - Select: id, job_id, started_at, operation, retry_count, source_file_name

     - Set error_message = 'Recovered from orphaned state'
     - Increment retry_count (use raw SQL: retry_count + 1)
     - Where id = generationId
   - Return true on success, false on error
   - Log the reset action

5. `getStuckJobsSummary(): Promise<{ stuckCount: number, oldestStuckMinutes: number }>` function:
   - Query count of generations in 'processing' state
   - Calculate how long the oldest one has been processing

  <name>Task 2: Create recovery manager</name>
  <files>lib/queue/recovery-manager.ts</files>
  <action>
Create a new file `lib/queue/recovery-manager.ts` with:

1. Import findOrphanedGenerations and resetGenerationToPending from '@/lib/db/job-queries'

2. Interface `RecoveryConfig`:
   - timeoutMinutes: number (default 15)
   - checkIntervalMs: number (default 60000 - 1 minute)

3. Class `RecoveryManager`:

   Private properties:
   - config: RecoveryConfig
   - intervalId: NodeJS.Timeout | null = null
   - isRunning: boolean = false

   Constructor:
   - Accept optional Partial<RecoveryConfig>
   - Merge with defaults: { timeoutMinutes: 15, checkIntervalMs: 60000 }

   Methods:

   a) `async runRecoveryCheck(): Promise<number>`:
      - Call findOrphanedGenerations(this.config.timeoutMinutes)
      - For each orphaned generation:
        - Log: `[Recovery] Recovering orphaned generation ${id} (stuck since ${started_at})`
        - Call resetGenerationToPending(id)
      - Return count of recovered generations

   b) `start(): void`:
      - If already running, log warning and return
      - Set isRunning = true
      - Run initial check immediately: await this.runRecoveryCheck()
      - Set up interval: setInterval(() => this.runRecoveryCheck(), checkIntervalMs)
      - Store intervalId
      - Log: `[Recovery] Started recovery manager (checking every ${checkIntervalMs/1000}s)`

   c) `stop(): void`:
      - If not running, return
      - Clear interval if exists
      - Set isRunning = false
      - Log: `[Recovery] Stopped recovery manager`

   d) `isActive(): boolean`:
      - Return isRunning

4. Singleton pattern:
   - let instance: RecoveryManager | null = null
   - `getRecoveryManager(): RecoveryManager`:
     - Create instance if null
     - Return instance

Export RecoveryManager class and getRecoveryManager function.
  </action>
