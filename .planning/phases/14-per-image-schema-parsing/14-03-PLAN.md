Add a new section to buildJobParserSystemPrompt after the Model Selection section:

```typescript
## Per-Image Operations

Users can assign different models or settings to specific images within a folder.

**Syntax patterns:**
- "use Seedream for X.jpg, Nano Banana for Y.jpg"
- "process A.jpg with Seedream high quality, B.jpg with Nano Banana 4K"
- "for folder 5: use Seedream on product-1.jpg and product-2.jpg, skip the rest"
- "generate all except A.jpg and B.jpg"

**When to use imageOperations:**
Use when user specifies DIFFERENT settings for specific files within a folder.
Parse as imageOperations array within the folder:

Example: "for folder 5, use Seedream for dress.jpg and Nano Banana 4K for model.jpg"
Result:
{
  folderPath: "5",
  operation: "Process images",
  model: "nano-banana-pro",  // folder default
  imageOperations: [
    {
      fileName: "dress.jpg",
      model: "seedream-4.5-edit",
      quality: "basic",
      imageSize: "landscape_16_9"
    },
    {
      fileName: "model.jpg",
      model: "nano-banana-pro",
      resolution: "4K"
    }
  ]
}

**When to use excludedFiles:**
Use when user wants to SKIP certain files but process all others with SAME settings.
Example: "process folder 5 except no.jpg and test.jpg"
Result: { folderPath: "5", excludedFiles: ["no.jpg", "test.jpg"], ... }

**IMPORTANT - Mutual Exclusivity:**
- If user specifies per-image operations, DO NOT also use excludedFiles
- imageOperations = explicit inclusion list (only these files processed)
- excludedFiles = explicit exclusion list (all files EXCEPT these processed)
- Never use both on the same folder

**Generation Count with Per-Image Operations:**
- If imageOperations specified: count = imageOperations.length
- If excludedFiles specified: count = totalFiles - excludedFiles.length
- This affects cost estimation - be accurate
```

Insert this section after the "## Model Selection" section and before "## Examples".

```typescript
// Normalize imageOperations if present
if (folder.imageOperations && Array.isArray(folder.imageOperations)) {
  // MUTUAL EXCLUSIVITY: If imageOperations exists, clear excludedFiles
  if (folder.excludedFiles && folder.excludedFiles.length > 0) {
    console.warn(`[AI Parse] Folder "${folder.folderPath}" has both imageOperations and excludedFiles - clearing excludedFiles`);
    folder.excludedFiles = [];
  }

  // Normalize each imageOperation
  folder.imageOperations = folder.imageOperations.map((imgOp: Record<string, unknown>) => {
    // Ensure model field exists
    if (!imgOp.model) {
      imgOp.model = folder.model || 'nano-banana-pro';
    }

    // Add model-specific defaults
    if (imgOp.model === 'nano-banana-pro') {
      if (!imgOp.resolution) {
        imgOp.resolution = '2K';
      }
      imgOp.quality = undefined;
      imgOp.imageSize = undefined;
    } else if (imgOp.model === 'seedream-4.5-edit') {
      if (!imgOp.quality) {
        imgOp.quality = 'basic';
      }
      if (!imgOp.imageSize) {
        imgOp.imageSize = 'landscape_16_9';
      }
      imgOp.resolution = undefined;
    }

    // Normalize resolution to uppercase
    if (imgOp.resolution && typeof imgOp.resolution === 'string') {
      imgOp.resolution = (imgOp.resolution as string).toUpperCase();
    }

    return imgOp;
  });
}
```
