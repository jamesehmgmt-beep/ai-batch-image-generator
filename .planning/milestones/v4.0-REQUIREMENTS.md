# Requirements: BulkImageGen v4.0

**Defined:** 2026-02-03
**Core Value:** Eliminate manual one-by-one image generation by letting AI understand complex natural language instructions and execute bulk image generations automatically.

## v4.0 Requirements

Per-generation prompts milestone: AI generates unique, tailored prompts for each individual generation.

### AI Prompt Generation

- [x] **PGEN-01**: AI generates a unique prompt for each individual generation (not one global prompt)
- [x] **PGEN-02**: When user specifies variations (e.g., "front, back, side, regular"), AI creates specific prompts for each
- [x] **PGEN-03**: When user says "generate N variations" without specifics, AI decides meaningful differences
- [x] **PGEN-04**: Generated prompts include all user requirements (model, background, preserve dress, etc.)

### Schema & Storage

- [x] **SCHM-01**: Generations table/schema supports storing individual prompts per generation
- [x] **SCHM-02**: Job creation populates individual prompts for each generation
- [x] **SCHM-03**: Queue execution uses the generation's specific prompt (not folder global)

### User Interface

- [x] **UI-01**: Preview page displays each generation's individual prompt
- [x] **UI-02**: User can edit individual prompts before execution
- [x] **UI-03**: Edited prompts are saved and used during execution
- [x] **UI-04**: Clear visual indication of which prompt belongs to which generation

## Out of Scope

| Feature | Reason |
|---------|--------|
| Prompt templates/presets | Future enhancement |
| Prompt history/favorites | Future enhancement |
| AI prompt suggestions while editing | Focus on core generation first |
