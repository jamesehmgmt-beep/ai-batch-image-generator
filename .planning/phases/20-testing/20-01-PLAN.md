  <name>Task 2: Create Unit Tests for calculateGenerationCount</name>
  <files>lib/job/generation-count.test.ts</files>
  <action>
Create lib/job/generation-count.test.ts with comprehensive test coverage:

Test structure using describe/it/expect from vitest:

1. "should use explicit generationCount when provided"
   - Input: folder with generationCount: 5, totalFilesInFolder: 10
   - Expected: 5

2. "should ignore zero generationCount and fall through to imageOperations"
   - Input: folder with generationCount: 0, imageOperations: [{fileName: 'a.jpg'}, {fileName: 'b.jpg'}]
   - Expected: 2

3. "should use imageOperations.length when no generationCount"
   - Input: folder with imageOperations: [{fileName: 'a.jpg'}, {fileName: 'b.jpg'}]
   - Expected: 2

4. "should return 0 for empty imageOperations array"
   - Input: folder with imageOperations: [], no generationCount
   - Expected: fall through to default (totalFiles - 0 = totalFiles)
   - NOTE: Empty array has length 0, so it falls through to case 3

5. "should default to totalFiles - excludedFiles.length"
   - Input: folder with excludedFiles: ['skip.jpg', 'test.jpg'], totalFilesInFolder: 10
   - Expected: 8

6. "should return totalFiles when no excludedFiles"
   - Input: folder with {} (empty), totalFilesInFolder: 5
   - Expected: 5

7. "should handle undefined excludedFiles"
   - Input: folder with excludedFiles: undefined
   - Expected: totalFilesInFolder

8. "should return 0 when exclusions exceed total files"
   - Input: folder with excludedFiles: ['a.jpg', 'b.jpg', 'c.jpg'], totalFilesInFolder: 2
   - Expected: 0 (Math.max(0, 2-3) = 0)

9. "should prioritize generationCount over imageOperations"
   - Input: folder with generationCount: 10, imageOperations: [{fileName: 'a.jpg'}]
   - Expected: 10

10. "should handle zero totalFiles"
    - Input: folder with {}, totalFilesInFolder: 0
    - Expected: 0

Import calculateGenerationCount from './generation-count'.
  </action>
