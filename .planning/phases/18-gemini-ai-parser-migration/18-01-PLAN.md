# Plan 18-01: Migrate AI Parser from Claude to Gemini [COMPLETE]

## Context

Phase 18 migrates the AI parsing from Claude to Google Gemini, making one API call per folder instead of batching.

## Requirements Addressed

- **GEMI-01**: Replace Claude with Google Gemini 3 Flash for image analysis (agentic vision)
- **GEMI-02**: Replace Claude with Gemini 3 Pro Preview for structured job generation
- **GEMI-03**: AI parsing makes one API call per folder (not batched)

## Tasks

### Task 1: Create Gemini Parser Module

**File**: `lib/ai/gemini-parser.ts`

- `parseSingleFolder()`: Parse instructions for one folder
- `parseJobWithGemini()`: Orchestrate per-folder parsing
- `buildFolderParserPrompt()`: Build prompt for single folder
- JSON response parsing with model-specific defaults
- Error handling for failed JSON parsing

### Task 2: Update Parse Route

**File**: `app/api/ai/parse/route.ts`

- Remove Claude SDK imports
- Import and use `parseJobWithGemini()`
- Simplify route handler (parsing logic moved to module)
- Keep per-folder validation logic

## Architecture

```
User Prompt
    ↓
parseJobWithGemini()
    ↓
Promise.all([
  parseSingleFolder(folder1),
  parseSingleFolder(folder2),
  ...
])
    ↓
Aggregate Results → ParsedJob
```

## Key Changes

1. **Per-folder API calls**: Each folder parsed independently
2. **Gemini Pro Preview**: Using `gemini-2.5-pro-preview-05-06` model
3. **JSON mode**: `responseMimeType: 'application/json'`
4. **Low temperature**: 0.1 for consistent parsing
