  <action>
Create migration file with the following SQL statements in order:

1. **Add model column to jobs table:**
   - ADD COLUMN model TEXT NOT NULL DEFAULT 'nano-banana-pro'
   - PostgreSQL 11+ makes constant default metadata-only (zero downtime)

2. **Add model column to generations table:**
   - ADD COLUMN model TEXT NOT NULL DEFAULT 'nano-banana-pro'
   - Same optimization applies

3. **Add Seedream-specific columns to generations:**
   - ADD COLUMN quality TEXT (nullable, for Seedream quality tier)
   - ADD COLUMN image_size TEXT (nullable, for Seedream size preset)
   - These are nullable because they only apply to Seedream jobs

4. **Add CHECK constraints:**
   - jobs: CHECK (model IN ('nano-banana-pro', 'seedream-4.5-edit'))
   - generations: CHECK (model IN ('nano-banana-pro', 'seedream-4.5-edit'))
   - generations.quality: CHECK (quality IS NULL OR quality IN ('basic', 'high'))

5. **Add indexes for model-based queries:**
   - CREATE INDEX idx_jobs_model ON jobs(model)
   - CREATE INDEX idx_generations_model ON generations(model)
   - CREATE INDEX idx_generations_model_state ON generations(model, state) for common queries

Include header comment explaining migration purpose and safety (constant defaults).

DO NOT include JSONB backfill - research confirmed it's optional and we'll read from typed columns.
  </action>
