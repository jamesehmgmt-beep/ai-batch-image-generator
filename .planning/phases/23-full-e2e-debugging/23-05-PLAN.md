<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 2: Manual download flow testing</name>
  <what-built>ZIP download of completed generations with folder structure</what-built>
  <how-to-verify>
Prerequisites: Have a completed job from 23-04 with at least one successful generation.

**Test 1: Download all results**
1. Navigate to results page (after job completion) or construct URL:
   http://localhost:3000/job/results/[jobId]
2. Click "Download All" button (or equivalent)
3. Verify:
   - [ ] ZIP file download starts
   - [ ] File name follows pattern: job-[id]-results.zip
   - [ ] Download completes (check browser downloads)

**Test 2: ZIP contents verification**
1. Open the downloaded ZIP file
2. Verify folder structure:
   - [ ] Top-level folders match original folder paths
   - [ ] No flat file dump (structure preserved)

3. Verify file contents:
   - [ ] Each image file opens correctly (not corrupted)
   - [ ] Images are actual generated results (not original sources)
   - [ ] File extension matches outputFormat (PNG or JPG)

4. Verify file naming:
   - [ ] Files follow pattern: [originalName]_generated.[ext]
   - [ ] Original source file name is referenced

**Test 3: File count accuracy**
1. Count files in ZIP
2. Compare to completed generation count from job
3. Verify:
   - [ ] Number matches (completed only, not failed)
   - [ ] Deleted generations are NOT included

**Test 4: Single folder download (if supported)**
1. If UI supports folder-specific download, try it
2. Verify:
   - [ ] Only selected folder's images in ZIP
   - [ ] File name reflects folder

**Test 5: Error handling - no completed generations**
1. Find or create a job with all failed/pending generations
2. Try to download
3. Verify:
   - [ ] Clear error message: "No completed generations found"
   - [ ] 404 response (not 500)

**Test 6: Large download (stress test - optional)**
1. If a job with many generations is available (10+)
2. Try download
3. Verify:
   - [ ] Download completes without timeout
   - [ ] Progress updates (if shown)
   - [ ] All files included

**Test 7: Image quality verification**
1. Open at least 2-3 generated images
2. Verify:
   - [ ] Images are high quality (not thumbnails)
   - [ ] Correct resolution based on job settings
   - [ ] No artifacts or corruption

Document any issues with:
- Steps to reproduce
- Expected vs actual file count
- Any corrupt/missing files
- Error messages
  </how-to-verify>

Type "approved" if all tests pass.
Type "issues: [description]" if problems found.
  </resume-signal>
