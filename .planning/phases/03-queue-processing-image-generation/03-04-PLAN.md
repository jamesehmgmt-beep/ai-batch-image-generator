Add utility function to job-manager.ts for looking up generations by kie.ai taskId:

```typescript
/**
 * Look up a generation record by its kie.ai taskId
 * Enables external systems to correlate taskIds with generation records (INTG-01)
 *
 * @param taskId - The kie.ai task ID
 * @returns GenerationRecord if found, null otherwise
 */
export async function getGenerationByTaskId(
  taskId: string
): Promise<GenerationRecord | null> {
  const supabase = await createServerSupabaseClient();

  const { data, error } = await supabase
    .from('generations')
    .select('*')
    .eq('task_id', taskId)
    .single();

  if (error || !data) {
    return null;
  }

  return data as GenerationRecord;
}
```

This function:
- Takes a kie.ai taskId as input
- Queries the generations table by task_id column
- Returns the full GenerationRecord if found
- Returns null if not found (no error thrown)

Use case: Webhook handlers or external systems can look up which generation corresponds to a kie.ai task callback.

Also add to exports:
- getGenerationByTaskId
