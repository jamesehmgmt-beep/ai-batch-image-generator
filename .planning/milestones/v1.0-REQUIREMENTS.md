# Requirements: BulkImageGen

**Defined:** 2026-01-24
**Core Value:** Eliminate manual one-by-one image generation by letting AI understand complex natural language instructions and execute bulk generations automatically.

## v1 Requirements

Requirements for initial release. Each maps to roadmap phases.

### Upload & Organization

- [x] **UPLD-01**: User can drag-drop folders into the browser
- [x] **UPLD-02**: Folder structure is preserved after upload (nested folders supported)
- [x] **UPLD-03**: System supports large batches (500+ photos per job)
- [x] **UPLD-04**: Files up to 30MB are supported (large product photos)
- [x] **UPLD-05**: User can see thumbnails of uploaded files before processing

### Photo Modes

- [x] **MODE-01**: System supports Reference Photo mode (photo used as-is in generation, no analysis)
- [x] **MODE-02**: System supports Analysis mode (AI examines photo content to understand what's in it)
- [x] **MODE-03**: AI infers correct mode from prompt context (e.g., "use as reference" vs "analyze")
- [x] **MODE-04**: User can manually override the mode if AI inference is wrong

### Prompt & Job Creation

- [x] **PMPT-01**: AI parses natural language prompts with folder references (e.g., "for folder named '5'...")
- [x] **PMPT-02**: AI understands file exclusions in prompts (e.g., "except no.jpg and test.jpg")
- [x] **PMPT-03**: AI asks clarifying questions until it fully understands user intent
- [x] **PMPT-04**: User can edit/refine AI's parsed interpretation before execution
- [x] **PMPT-05**: System shows cost estimation before job runs
- [x] **PMPT-06**: AI extracts resolution (1K/2K/4K) and aspect ratio from prompt text

### Queue & Processing

- [x] **PROC-01**: System manages queue with max 20 concurrent generations (kie.ai limit)
- [x] **PROC-02**: Real-time progress tracking with progress bar and ETA
- [x] **PROC-03**: Pre-execution summary shows: total photo count, resolutions, aspect ratios, folder breakdown
- [x] **PROC-04**: Auto-retry on generation failure until successful (never skip)
- [x] **PROC-05**: When one generation completes, next in queue starts automatically

### Results & Export

- [x] **RSLT-01**: User can download results organized by source folder
- [x] **RSLT-02**: User can browse processing history of past jobs
- [x] **RSLT-03**: User can choose output format: PNG or JPEG
- [x] **RSLT-04**: Generated images are stored in Supabase with job association

### Authentication & UI

- [x] **AUTH-01**: App is password-protected (password: 16063001)
- [x] **AUTH-02**: Modern/minimal dark mode UI dashboard

### Integration

- [x] **INTG-01**: kie.ai Nano Banana Pro API integration for image generation
- [x] **INTG-02**: Supabase Storage for image files
- [x] **INTG-03**: Supabase for job state and history persistence
- [x] **INTG-04**: Claude Sonnet 4.5 (Anthropic API) for prompt parsing and clarifying questions
