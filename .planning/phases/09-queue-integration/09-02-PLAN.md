<task type="auto">
  <name>Task 2: Refactor executeGeneration to use strategies</name>
  <files>lib/queue/generation-queue.ts</files>
  <action>
Refactor the `executeGeneration()` method to use strategy pattern instead of hardcoded kie.ai calls.

**Replace this code block (Steps 3-5 in current executeGeneration):**
```typescript
// Step 3: Create task on kie.ai
const payload: KieAIPayload = {
  model: 'nano-banana-pro',
  input: {
    prompt: finalPrompt,
    image_input: job.referenceImageUrls,
    aspect_ratio: job.aspectRatio,
    resolution: job.resolution || '2K',
    output_format: (job.outputFormat?.toLowerCase() as 'png' | 'jpg') || 'png',
  },
};

console.log(`[Queue] Calling kie.ai for generation ${job.id}:`, {
  prompt: finalPrompt.substring(0, 100),
  photoMode: job.photoMode,
  imageCount: job.referenceImageUrls.length,
  resolution: job.resolution,
});

const taskId = await createKieAITask(payload);
console.log(`[Queue] kie.ai task created: ${taskId}`);
```

**With this strategy-based code:**
```typescript
// Step 3: Get strategy for this generation's model
const strategy = getModelStrategy(job.model);

// Step 4: Build model-specific parameters
const params = buildModelParams(job, strategy, finalPrompt);

// Step 5: Validate before API call
strategy.validateParams(params);

console.log(`[Queue] Using ${strategy.capabilities.displayName} for generation ${job.id}:`, {
  model: job.model,
  prompt: finalPrompt.substring(0, 100),
  photoMode: job.photoMode,
  imageCount: params.referenceImages.length,
  maxRefs: strategy.capabilities.maxReferenceImages,
});

// Step 6: Create task via strategy
const taskId = await strategy.createTask(params);
console.log(`[Queue] Task created via ${strategy.capabilities.displayName}: ${taskId}`);
```

**Also replace the polling call:**
```typescript
// Step 5: Poll for completion
const { resultUrl } = await pollTaskCompletion(taskId);
```

**With:**
```typescript
// Step 8: Poll for completion via strategy
const { resultUrl } = await strategy.pollTask(taskId);
```

**Update step numbering** in comments to reflect new flow:
1. Update state to 'processing'
2. Prepare prompt (with optional Claude analysis)
3. Get strategy for model
4. Build model-specific parameters
5. Validate parameters
6. Create task via strategy
7. Update database with task_id
8. Poll for completion via strategy
9. Update state to 'completed'

**After refactoring, remove unused imports:**
- Remove `KieAIPayload` from import (no longer needed)
- Keep `createKieAITask, pollTaskCompletion, getKieApiKey` for now - they may be used elsewhere or can be removed in cleanup phase
