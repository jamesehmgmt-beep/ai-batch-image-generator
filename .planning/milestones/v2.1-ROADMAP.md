# Milestone v2.1: AI Parsing & Bug Fixes

**Status:** SHIPPED 2026-01-30
**Phases:** 13-15
**Total Plans:** 9

## Overview

v2.1 focuses on AI parsing accuracy and per-image model selection. This milestone fixes the preview page bug blocking user flows, extends schemas to support image-level operations (not just folder-level), updates the AI parser to understand per-image model assignments and exclusions, and adds a confirmation step so users can review AI interpretation before job creation. Three targeted phases: bug fixes first, then schema/parsing infrastructure, then confirmation UI.

## Milestone Summary

**Key Decisions:**

| ID | Phase-Plan | Decision | Rationale |
|----|-----------|----------|-----------|
| error-propagation-500 | 13-01 | Return 500 with genError details when Supabase insert fails | Database errors are server errors, client needs specific message |
| pure-generation-count | 14-02 | Extract generation count logic into pure function | Single source of truth prevents count mismatch bugs |
| case-insensitive-matching | 14-04 | toLowerCase() comparison for file names | Users might type "X.jpg" when file is "x.jpg" |
| generation-count-display | 15-01 | Use calculateGenerationCount for all count displays | Ensures UI interpretation matches actual execution logic |
| local-state-onChange | 15-02 | Component uses onChange callback instead of direct context mutation | Enables reuse in different contexts |

**Issues Resolved:**
- Preview page "failed to fetch generations" error
- Generation count mismatch (12 expected vs 28 actual)
- Per-image model selection not supported

**Technical Debt Incurred:**
- Phase 14 missing formal VERIFICATION.md (verified via SUMMARY.md completion)
- Dual code paths for generation creation (intentional for preview display)
