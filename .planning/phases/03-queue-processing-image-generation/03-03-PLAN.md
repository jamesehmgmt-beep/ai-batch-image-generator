<task type="auto">
  <name>Task 1: Create job manager utilities</name>
  <files>lib/job/job-manager.ts</files>
  <action>
Create job management functions for creating and expanding jobs:

1. Import types: ParsedJob, JobRecord, GenerationJob, GenerationRecord
2. Import createServerSupabaseClient
3. Import calculateCostEstimate from './cost-estimation'

4. createJob function:
   - Input: { sessionId: string, parsedJob: ParsedJob, fileCountByFolder: Record<string, number> }
   - Calculate cost estimate using calculateCostEstimate
   - Calculate total generations (sum of files across all folders minus exclusions)
   - Insert into jobs table:
     - session_id, parsed_job (JSON), estimated_cost, total_generations, state: 'pending'
   - Return created job record with id

5. expandJobToGenerations function:
   - Input: { jobId: string, parsedJob: ParsedJob, filesByFolder: Record<string, string[]> }
   - For each folder in parsedJob.job.folders:
     - Get files for this folder path from filesByFolder
     - Filter out excludedFiles
     - For each remaining file:
       - Create GenerationJob object:
         - Generate UUID for id
         - jobId: parent job id
         - folderPath: folder.folderPath
         - operation: folder.operation (or globalPrompt if folder operation is empty)
         - resolution: folder.resolution
         - aspectRatio: folder.aspectRatio
         - photoMode: folder.photoMode
         - referenceImageUrls: [file URL] (from filesByFolder - see mapping below)
         - sourceFileName: filename
   - Batch insert all generation records into generations table with state: 'pending'
   - Return array of GenerationJob objects

6. getJobSummary function:
   - Input: jobId: string
   - Query job record with counts
   - Query generation counts by state
   - Return summary: {
       job: JobRecord,
       generations: {
         pending: number,
         processing: number,
         completed: number,
         failed: number
       }
     }

7. getJobGenerations function:
   - Input: jobId: string
   - Query all generation records for job
   - Return as GenerationRecord[]

Helper: buildStorageUrl(sessionId: string, folderPath: string, fileName: string): string
- Returns Supabase storage public URL for the file
- Format: ${SUPABASE_URL}/storage/v1/object/public/images/${sessionId}/${folderPath}/${fileName}
  </action>

  <done>Job manager exports createJob, expandJobToGenerations, getJobSummary, getJobGenerations</done>

<task type="auto">
  <name>Task 3: Create job execution API endpoint</name>
  <files>app/api/job/execute/route.ts</files>
  <action>
Create POST endpoint to start job execution:

1. Import getQueueManager from '@/lib/queue/generation-queue'
2. Import { expandJobToGenerations, getJobSummary } from '@/lib/job/job-manager'
3. Import createServerSupabaseClient

Request body:
```typescript
{
  jobId: string;
  filesByFolder: Record<string, string[]>;  // Actual file URLs per folder path
}
```

Processing steps:
1. Fetch job record from database (includes parsed_job JSON)
2. Validate job exists and state is 'pending'
3. Update job state to 'processing', set started_at
4. Call expandJobToGenerations with explicit filesByFolder -> referenceImageUrls mapping:
   ```typescript
   // For each folder in parsedJob.job.folders:
   const folderPath = folder.folderPath;
   const fileUrls = filesByFolder[folderPath] || [];

   // Filter out excluded files by filename
   const excludedFileNames = folder.excludedFiles || [];
   const validUrls = fileUrls.filter(url => {
     const fileName = url.split('/').pop() || '';
     return !excludedFileNames.includes(fileName);
   });

   // For each valid URL, create generation with:
   // - referenceImageUrls: [url] (single file per generation, max 8 if multiple needed)
   // - Validate URL format: must start with http:// or https://
   // - Validate array length: referenceImageUrls.length <= 8 per generation

   // The URL from filesByFolder IS the referenceImageUrl for kie.ai
   ```
5. Get queue manager instance
6. Add all generations to queue using addBatch (non-blocking)
7. Return immediately with job summary (don't wait for completion)

Response (202 Accepted):
```typescript
{
  success: true,
  message: 'Job execution started',
  job: {
    id: string;
    totalGenerations: number;
    state: 'processing';
  },
  queueStatus: {
    pending: number;
    queued: number;
    total: number;
  }
}
```

Important: Do NOT await queue completion in the API handler.
The queue processes in the background. Client polls /api/job/status for updates.

Error handling:
- 404 if job not found
- 400 if job not in 'pending' state
- 400 if filesByFolder contains invalid URLs (not http/https)
- 500 for other errors
