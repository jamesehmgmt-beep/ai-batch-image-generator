Page structure:
1. Header with title "Confirm Interpretation" and mode toggle (View/Edit buttons)
2. Interpretation text (always visible, sticky at top in edit mode)
3. InterpretationSummary component (generation counts)
4. Per-folder details section:
   - For each folder in parsedJob.job.folders:
     - Show folder path as header
     - If folder.imageOperations exists: show PerImageAssignments
     - Else if folder.excludedFiles exists: show FolderExclusions
     - Show operation text preview
5. Action buttons: "Edit Prompt" (back to review) and "Approve & Continue" (to cost)

State management:
- mode: 'view' | 'edit' (default 'view')
- Use useJobContext() for parsedJob and fileCountByFolder
- All edits go through updateParsedJob or setParsedJob

View mode:
- Display-only rendering of all components
- Pass isEditable=false to PerImageAssignments and FolderExclusions

Edit mode:
- Pass isEditable=true to child components
- Handle onChange callbacks to update job context
- Show "Modified" badge if changes made (compare to original)
- Preserve changes when switching back to view mode

onChange handlers:
```typescript
const handleImageOperationsChange = (folderIndex: number, updated: ImageOperation[]) => {
  updateParsedJob((job) => {
    if (!job.job) return job;
    const newFolders = [...job.job.folders];
    newFolders[folderIndex] = {
      ...newFolders[folderIndex],
      imageOperations: updated,
    };
    return { ...job, job: { ...job.job, folders: newFolders } };
  });
};

const handleExclusionsRemove = (folderIndex: number, fileName: string) => {
  updateParsedJob((job) => {
    if (!job.job) return job;
    const newFolders = [...job.job.folders];
    const folder = newFolders[folderIndex];
    newFolders[folderIndex] = {
      ...folder,
      excludedFiles: folder.excludedFiles?.filter(f => f !== fileName) || [],
    };
    return { ...job, job: { ...job.job, folders: newFolders } };
  });
};

const handleExclusionsAdd = (folderIndex: number, fileName: string) => {
  updateParsedJob((job) => {
    if (!job.job) return job;
    const newFolders = [...job.job.folders];
    const folder = newFolders[folderIndex];
    newFolders[folderIndex] = {
      ...folder,
      excludedFiles: [...(folder.excludedFiles || []), fileName],
    };
    return { ...job, job: { ...job.job, folders: newFolders } };
  });
};
```
