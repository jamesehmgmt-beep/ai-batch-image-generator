  <action>
Create lib/models/types.ts with the following types:

1. **ModelId** - String literal union type:
   ```typescript
   export type ModelId = 'nano-banana-pro' | 'seedream-4.5-edit';
   ```

2. **ModelCapabilities** - Interface describing model capabilities:
   ```typescript
   export interface ModelCapabilities {
     id: ModelId;
     displayName: string;
     maxReferenceImages: number;  // Nano: 8, Seedream: 14
     supportedAspectRatios: string[];
     costPerGeneration: Record<string, number>;  // By resolution/quality
   }
   ```

3. **ModelGenerationParams** - Common parameters for all models:
   ```typescript
   export interface ModelGenerationParams {
     prompt: string;
     referenceImages: string[];  // URLs
     aspectRatio: string;
   }
   ```

4. **NanoBananaParams** - Nano Banana Pro specific params:
   ```typescript
   export interface NanoBananaParams extends ModelGenerationParams {
     resolution: '1K' | '2K' | '4K';
     outputFormat: 'png' | 'jpg';
   }
   ```

5. **SeedreamParams** - Seedream 4.5 Edit specific params:
   ```typescript
   export interface SeedreamParams extends ModelGenerationParams {
     quality: 'basic' | 'high';
     imageSize: string;  // e.g., 'landscape_16_9', 'square'
   }
   ```

6. **ModelStrategy** - The core strategy interface:
   ```typescript
   export interface ModelStrategy {
     readonly capabilities: ModelCapabilities;

     // Create kie.ai task, returns taskId
     createTask(params: ModelGenerationParams): Promise<string>;

     // Poll for task completion, returns result URL
     pollTask(taskId: string): Promise<{ resultUrl: string }>;

     // Validate model-specific parameters before API call
     validateParams(params: ModelGenerationParams): void;
   }
   ```

Add JSDoc comments explaining each type's purpose. Export all types.
