  <what-built>
AI-powered prompt generation system with three intent modes:
1. UNIFORM: Same prompt for all images (default)
2. EXPLICIT_VARIATIONS: User-specified variations (e.g., "front, back, side")
3. IMPLICIT_VARIATIONS: AI-decided meaningful differences

The system analyzes user intent using Claude Sonnet 4.5 with extended thinking, then generates appropriate prompts for each image.
  </what-built>
  <how-to-verify>
**Setup:**
1. Start the dev server: `npm run dev`
2. Open browser to http://localhost:3000

**Test 1: UNIFORM Mode (PGEN-01, most common case)**
1. Upload a folder with 3+ images
2. Enter prompt: "put each hijab on a woman's head"
3. Submit and proceed to confirmation page
4. Check database or console logs to verify:
   - All images have the SAME prompt
   - Prompt matches user's request without embellishments

Expected: All generations have identical prompt "put each hijab on a woman's head" (or very similar)

**Test 2: EXPLICIT_VARIATIONS Mode (PGEN-02)**
1. Upload a folder with 3+ images
2. Enter prompt: "create product photos with front, back, and side views"
3. Submit and proceed to confirmation page
4. Check database or console logs to verify:
   - Image 1 prompt contains "front" variation
   - Image 2 prompt contains "back" variation
   - Image 3 prompt contains "side" variation

Expected: Prompts cycle through the specified variations

**Test 3: IMPLICIT_VARIATIONS Mode (PGEN-03)**
1. Upload a folder with 3+ images
2. Enter prompt: "generate 3 unique variations of a model wearing the dress"
3. Submit and proceed to confirmation page
4. Check database or console logs to verify:
   - Each image has a DIFFERENT prompt
   - Differences are meaningful (angle, style, composition)
   - Core operation preserved (model wearing dress)

Expected: AI generates unique but related prompts for each image

**Test 4: Backward Compatibility**
1. Upload a folder with images
2. Use existing workflow (should still work without errors)
3. Verify job creation succeeds

Expected: System works with or without the new intent analysis
