Prerequisites: Complete upload (23-01), parsing (23-02), and confirmation (23-03). Be on the cost page ready to create job.

**WARNING: This test will make REAL API calls and generate images. Use a small test set (2-3 images) to minimize costs.**

**Test 1: Cost page and job creation**
1. On /job/cost page, verify:
   - [ ] Cost breakdown shows per-folder costs
   - [ ] Total cost is calculated correctly
   - [ ] Model-specific pricing is applied

2. Click "Create Job" or equivalent button
3. Verify:
   - [ ] Loading state shows
   - [ ] Job is created (check Network tab for /api/job/create response)
   - [ ] Response includes jobId and totalGenerations
   - [ ] Navigation to preview/progress page works

**Test 2: Generation record verification**
1. In browser DevTools Network tab, check /api/job/create response:
   - [ ] success: true
   - [ ] job.totalGenerations matches expected count
   - [ ] No error messages

2. Optional: Check Supabase directly:
   - Verify job record exists in 'jobs' table
   - Verify generation records exist in 'generations' table
   - Verify state = 'pending' initially

**Test 3: Queue execution**
1. On preview page, verify execution starts (may auto-start):
   - [ ] "Start Generation" button works (if present)
   - [ ] /api/job/execute is called (check Network tab)
   - [ ] Response shows success and queue status

2. Verify queue is processing:
   - [ ] Progress indicator shows (e.g., "1/3 completed")
   - [ ] Individual generation states update (pending -> processing -> completed/failed)

**Test 4: Progress updates**
1. Wait for generations to process (may take 1-2 minutes each)
2. Verify real-time updates:
   - [ ] Progress bar/counter updates as generations complete
   - [ ] Completed generations show preview thumbnails
   - [ ] Generation results are visible

**Test 5: Error handling**
1. If any generation fails:
   - [ ] Error state is shown clearly
   - [ ] Error message is descriptive
   - [ ] Failed generation can be retried (if supported)

2. If API is rate limited or unavailable:
   - [ ] Retry logic kicks in
   - [ ] User sees appropriate message

**Test 6: Completion state**
1. Wait for all generations to complete (or timeout after 10 minutes)
2. Verify:
   - [ ] Job state shows 'completed'
   - [ ] All generations have result_url (for completed)
   - [ ] "Download Results" option appears

**Important monitoring:**
- Watch browser console for errors
- Watch Network tab for failed requests
- Note any timeouts or hanging requests

Document any issues with reproduction steps and error messages.
