   - model: z.literal('seedream-4.5-edit')
   - quality: SeedreamQualitySchema.default('basic')

   - resolution: z.undefined().optional()

4. Create ImageOperationSchema as z.discriminatedUnion('model', [...])

5. Export ImageOperation type using z.infer

Place these AFTER the existing folder schemas and BEFORE FolderOperationSchema definition.

<task type="auto">
  <name>Task 2: Extend FolderOperationSchema with imageOperations</name>
  <files>lib/ai/schemas/job.ts</files>
  <action>
Modify the existing folder schemas to include imageOperations:

1. Add to BaseFolderOperationSchema:
   ```typescript
   imageOperations: z.array(ImageOperationSchema).optional()
     .describe('Per-image overrides: different models or settings for specific files. Mutually exclusive with excludedFiles - if imageOperations exists, only those files are processed.')
   ```

2. The discriminated union (NanoBananaFolderSchema, SeedreamFolderSchema) will automatically inherit this field since they extend BaseFolderOperationSchema.

Note: Do NOT add .refine() for mutual exclusivity with excludedFiles - that makes JSON schema conversion harder. We'll handle this in normalization (app/api/ai/parse/route.ts) in a later plan.
