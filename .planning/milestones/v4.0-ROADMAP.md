# Milestone v4.0: Per-Generation Prompts

**Status:** ✅ SHIPPED 2026-02-04
**Phases:** 25-27
**Total Plans:** 4+

## Overview

AI generates unique, tailored prompts for each individual generation instead of using a single global prompt. Users can specify variations (e.g., "front, back, side") and the AI creates specific prompts for each, or let AI decide meaningful variations automatically.

## Phases

### Phase 25: Schema & Storage

**Goal**: Database schema supports storing individual prompts per generation
**Depends on**: Phase 21 (Claude Migration)
**Plans**: 2 plans

Plans:

- [x] 25-01-PLAN.md - Database migration, TypeScript types, and prompt generator utility
- [x] 25-02-PLAN.md - Job creation and queue execution integration

**Details:**
- Added `prompt` TEXT column to generations table (nullable for backward compatibility)
- Updated GenerationJob (prompt?: string) and GenerationRecord (prompt: string | null) types
- Created prompt generator utility with pass-through implementation for Phase 25
- Job creation populates prompt field at creation time
- Queue execution uses prompt with fallback to operation field

### Phase 26: AI Prompt Generation

**Goal**: AI generates unique, tailored prompts for each individual generation based on user intent
**Depends on**: Phase 25
**Plans**: 2+ plans

Plans:

- [x] 26-01-PLAN.md - Intent analysis types, system prompt, and analysis function
- [x] 26-02-PLAN.md - Enhanced prompt generator with mode handling

**Details:**
- Intent analysis using Claude Sonnet 4.5 with extended thinking (3000 token budget)
- Three modes: uniform (default), explicit-variations (user-specified), implicit-variations (AI-decided)
- Intent cache prevents redundant API calls within same folder
- Confidence threshold (0.7) forces uniform mode when ambiguous
- Fallback chain ensures job creation never fails

### Phase 27: UI Integration

**Goal**: Users can view and edit individual prompts on preview page
**Depends on**: Phase 26
**Plans**: Direct implementation (no formal plans)

**Details:**
- Preview page displays each generation's individual prompt
- User can edit individual prompts before execution
- Edited prompts are saved and used during execution
- Clear visual indication of which prompt belongs to which generation

## Milestone Summary

**Key Decisions:**

- TEXT column type (no length limit, same performance as VARCHAR)
- Nullable column for zero-downtime migration
- Intent analysis with 3000 token thinking budget
- Confidence threshold 0.7 for uniform mode forcing
- Pre-generation prompt creation at job creation time
- Fallback pattern: prompt || operation for backward compatibility

**Issues Resolved:**

- Prompts weren't reaching kie.ai - fixed execute route mapping
- Preview UI showed operation instead of prompt - updated API and component

**Issues Deferred:**

- None

**Technical Debt Incurred:**

- Phase 27 implemented without formal planning docs
- Debug logging added (should be cleaned up later)
