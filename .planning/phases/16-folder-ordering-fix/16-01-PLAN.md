# Plan 16-01: Fix Folder Ordering in Upload Processing [COMPLETE]

## Context

Users report folders appear in random order instead of maintaining drag-and-drop order. Root cause analysis reveals:

1. **Race condition**: `extractFilesFromDrop()` uses `Promise.all()` for parallel processing, causing folders to be added to `folderTree[]` in completion order rather than drop order
2. **Filesystem APIs**: Both `dirHandle.values()` and `reader.readEntries()` don't guarantee order
3. **No explicit ordering**: Neither upload code nor context preserves original drop index

## Requirements Addressed

- **ORDR-01**: Folder upload maintains drag-and-drop order throughout the UI
- **ORDR-02**: Per-folder prompt UI displays folders in upload order

## Tasks

### Task 1: Track Original Drop Index

**File**: `lib/upload/file-system.ts`

Modify `extractFilesFromDrop()` to track each item's original index:

```typescript
// Before Promise.all, create indexed results array
const indexedResults: Array<{ index: number; node: FolderNode | null }> = []

for (let i = 0; i < items.length; i++) {
  const item = items[i]
  if (item.kind !== 'file') {
    indexedResults.push({ index: i, node: null })
    continue
  }
  // ... process item, storing result with index
}
```

### Task 2: Sort FolderTree After Processing

**File**: `lib/upload/file-system.ts`

After `Promise.all()` completes, sort `folderTree` by original index:

```typescript
await Promise.all(processPromises)

// Sort folderTree by original drop order
folderTree.sort((a, b) => {
  const indexA = dropOrderMap.get(a.path) ?? Infinity
  const indexB = dropOrderMap.get(b.path) ?? Infinity
  return indexA - indexB
})
```

### Task 3: Sort Children Within Folders Alphabetically

**File**: `lib/upload/file-system.ts`

Add alphabetical sorting to `traverseDirectory()` and `traverseWebkitDirectory()` for consistent ordering within folders:

```typescript
// After collecting all entries, sort alphabetically
treeNodes.sort((a, b) => a.name.localeCompare(b.name))
```
