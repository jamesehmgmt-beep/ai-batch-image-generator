# Requirements: BulkImageGen v2.1

**Defined:** 2026-01-29
**Core Value:** Eliminate manual one-by-one image generation by letting AI understand complex natural language instructions and execute bulk generations automatically.

## v2.1 Requirements

Requirements for v2.1 AI Parsing & Bug Fixes release. Focuses on fixing parsing accuracy and enabling per-image model selection.

### Per-Image Model Selection

- [x] **PIMG-01**: AI parser can assign different models to different images within the same folder
- [x] **PIMG-02**: Schema supports image-specific operations (not just folder-level)
- [x] **PIMG-03**: Job expansion creates generations with correct per-image model settings
- [x] **PIMG-04**: Prompts like "use Seedream for X.jpg, Nano Banana for Y.jpg" are correctly parsed

### AI Parsing Accuracy

- [x] **PARS-01**: AI shows interpretation summary before job creation (confirmation step)
- [x] **PARS-02**: User can approve or correct AI's interpretation before proceeding
- [x] **PARS-03**: AI correctly understands file exclusions ("except X.jpg and Y.jpg")
- [x] **PARS-04**: Generation count matches user intent (no over/under-counting)
- [x] **PARS-05**: AI system prompt updated with per-image operation examples

### Bug Fixes

- [x] **BUGF-01**: Fix "failed to fetch generations" error on preview page
- [x] **BUGF-02**: Preview page loads correctly after cost estimation
