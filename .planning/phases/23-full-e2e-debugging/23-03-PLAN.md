<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 2: Manual confirmation page testing</name>
  <what-built>Confirmation page for reviewing AI interpretation before job creation</what-built>
  <how-to-verify>
Prerequisites: Complete upload (23-01) and AI parsing (23-02) first. You should have a valid ParsedJob in session.

Navigate to http://localhost:3000/job/confirm and test:

**Test 1: Summary display (View mode)**
1. Verify confirmation page loads with parsed job data
2. Check interpretation summary:
   - [ ] AI interpretation text is displayed
   - [ ] Total generation count is shown
   - [ ] Per-folder file counts are accurate
   - [ ] Model badges show correct model (nano-banana-pro or seedream)

**Test 2: Generation count accuracy (CRITICAL)**
1. Compare displayed count to expected count
2. Calculate expected: For each folder, count = (file count - excluded files) * (generationCount or 1)
3. Verify:
   - [ ] Total generations matches calculation
   - [ ] Per-folder counts match

**Test 3: Folder details**
1. Review each folder in the details section
2. Verify:
   - [ ] Folder path is correct
   - [ ] Operation text matches what AI parsed
   - [ ] Model selection is correct
   - [ ] Excluded files are listed (if any)
   - [ ] Per-image assignments shown (if any)

**Test 4: Edit mode toggle**
1. Click "Edit" button to switch to edit mode
2. Verify:
   - [ ] UI changes to show editable fields
   - [ ] AI interpretation card becomes sticky (if implemented)

**Test 5: Editing functionality**
1. In edit mode, try to:
   - [ ] Remove an excluded file (click X on file badge)
   - [ ] Add an excluded file (if UI supports)
   - [ ] Modify per-image assignment (if applicable)
2. Switch back to View mode
3. Verify:
   - [ ] Changes are reflected
   - [ ] Generation count updates accordingly

**Test 6: Navigation flow**
1. Click "Edit Prompt" button
2. Verify:
   - [ ] Navigation to /job/review works
   - [ ] Parsed job data is preserved

3. Return to confirm page
4. Click "Approve & Continue" button
5. Verify:
   - [ ] Navigation to /job/cost works
   - [ ] All data carries forward

**Test 7: Empty state handling**
1. Clear session (delete sessionStorage key in DevTools)
2. Navigate directly to /job/confirm
3. Verify:
   - [ ] Empty state message shows
   - [ ] Link to create job is provided
   - [ ] No crash or console errors

Document any issues with reproduction steps.
