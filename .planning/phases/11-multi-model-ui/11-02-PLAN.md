Create a new component `components/job/per-folder-prompts.tsx` with:

1. Import shadcn/ui Card, CardContent, CardHeader, CardTitle, Badge, Textarea
2. Import useJobContext from lib/session/job-context
3. Import Folder icon from lucide-react

4. Implement PerFolderPrompts component:
   - Read folders, fileCountByFolder, parsedJob, updateParsedJob from context
   - Early return null if parsedJob.job.promptMode !== 'per-folder'

5. Reconcile uploaded folders with parsed folders:
   - ALWAYS iterate over context.folders (source of truth for uploaded folders)
   - For each folderPath in context.folders:
     a. Find matching folder in parsedJob.job.folders by folderPath
     b. If MATCH FOUND: use that folder's operation as textarea value
     c. If NO MATCH FOUND (folder uploaded but not yet in parsedJob):
        - Show empty textarea with placeholder "Enter prompt for {folderPath}..."
        - On first edit, addNewFolder will create the entry

   ```tsx
   // Reconciliation logic:
   {folders.map((folderPath) => {
     const parsedFolder = parsedJob?.job?.folders?.find(f => f.folderPath === folderPath);
     const currentPrompt = parsedFolder?.operation ?? '';
     const fileCount = fileCountByFolder.get(folderPath) ?? 0;

     return (
       <Card key={folderPath}>
         <CardHeader>
           <CardTitle className="flex items-center gap-2">
             <Folder className="h-4 w-4" />
             {folderPath}
             <Badge variant="secondary">{fileCount} images</Badge>
           </CardTitle>
         </CardHeader>
         <CardContent>
           <Textarea
             value={currentPrompt}
             onChange={(e) => updateFolderPrompt(folderPath, e.target.value)}
             placeholder={`Enter prompt for ${folderPath}...`}
           />
         </CardContent>
       </Card>
     );
   })}
   ```

6. updateFolderPrompt(folderPath, newPrompt) function:
   - Find folder index in parsedJob.job.folders by folderPath
   - If found (index >= 0): update operation field at that index
   - If NOT found (index === -1): Add new folder entry with:
     ```tsx
     const newFolder = {
       folderPath,
       operation: newPrompt,
       model: parsedJob.job.model,  // inherit job default model
       aspectRatio: 'auto',
       photoMode: 'reference',
       // Add model-specific defaults based on job.model:
       ...(parsedJob.job.model === 'nano-banana-pro'
         ? { resolution: '2K' }
         : { quality: 'basic', imageSize: 'landscape_16_9' })
     };
     ```

7. Show validation warning if any folder has empty operation when user tries to proceed:
   - Check: folders.some(fp => !parsedJob.job.folders.find(f => f.folderPath === fp)?.operation?.trim())
   - Display inline warning text below empty textareas

PITFALL AVOIDANCE:
- Always derive folder list from context.folders (uploaded folders), NOT parsedJob.job.folders
- Handle case where folder exists in uploads but not yet in parsedJob (show empty textarea)
- Empty textarea should NOT crash - just pass empty string to controlled input

Style: Match folder-operation-editor.tsx Card styling for consistency.
