# Requirements: BulkImageGen v3.0

**Defined:** 2026-01-30
**Core Value:** Eliminate manual one-by-one image generation by letting AI understand complex natural language instructions and execute bulk generations automatically.

## v3.0 Requirements

Requirements for v3.0 Gemini Migration & Bug Fixes release. Focuses on switching from Claude to Google Gemini, fixing generation count bugs, and ensuring comprehensive testing.

### Folder Ordering

- [x] **ORDR-01**: Folder upload maintains drag-and-drop order throughout the UI
- [x] **ORDR-02**: Per-folder prompt UI displays folders in upload order (not random)

### Gemini Integration

- [x] **GEMI-01**: Replace Claude with Google Gemini 3 Flash for image analysis (agentic vision)
- [x] **GEMI-02**: Replace Claude with Gemini 3 Pro Preview for structured job generation
- [x] **GEMI-03**: AI parsing makes one API call per folder (not batched)
- [x] **GEMI-04**: Gemini SDK integrated with proper error handling and retry logic
- [x] **GEMI-05**: API key configuration via environment variable (GOOGLE_AI_API_KEY)

### Bug Fixes

- [x] **BUGF-03**: Generation count on cost page matches preview page count exactly
- [x] **BUGF-04**: Excluded files are not processed in job execution

### Testing

- [x] **TEST-01**: Unit tests for calculateGenerationCount function
- [x] **TEST-02**: Integration tests for Gemini API parsing
- [x] **TEST-03**: E2E test for complete job flow (upload -> parse -> execute -> download)
